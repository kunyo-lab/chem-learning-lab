# chem\learning\lab
高校化学の学習用Web教材を制作するプロジェクト

## 現在制作中
元素記号テスト

### 現在できること
- 原子番号1〜20からランダム出題
- 元素記号 → 元素名
- 元素名 → 元素記号
- 10問出題
- 得点表示

### 現段階での修正点・検討事項
- 元素記号を答える際、全角入力だと、あっていても不正解になってしまう。アルファベットは強制的に入力モードを半角にするか、全角でも正解になるように設定するか
- 元素名の変換ミス、特にカタカナをひらがなとかどうするか。

## 今後追加したい機能
- 問題数10問／20問の選択
- 出題範囲の選択
- 周期表から元素を選択
- 学習記録の保存
- 苦手元素の再出題
