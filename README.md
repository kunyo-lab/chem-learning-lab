# chem\learning\lab
高校化学の学習用Web教材を制作するプロジェクト

## 現在制作中
元素記号テスト

## 現在のバージョン
v0.1.1

### 現在できること
- 原子番号1〜20からランダム出題
- 元素記号 → 元素名
- 元素名 → 元素記号
- 10問出題
- 得点表示
- 全角英字を半角英字に変換して判定
- 元素記号の大文字・小文字を区別して判定
- 大文字・小文字についての注意書きを表示
